elementos
cada etiqueta tiene un elemento, el elemento determina el comportamiento y el tipo de etiqueta y el tip

- a = Ancla, sirve para hacer hipervinculos, de cierre
- img = permite poner imagenes en una pag, de autocierre
- video = sirve para poner un video en una pagina, de cierre

Atributos:sirven para modificar o configurar el comportamiento de una etiqueta
siempre van dentro de la etiqueta de la apertura
EJEMPLO
CODIGO: <a href="https://www.mercadolibre.com.ar/">ir a mercado libre</a>
